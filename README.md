# itvx-adblocker

Chrome/Firefox extension to remove ad breaks from ITVX

## Installation

### Chrome
Download the `itvx-adblocker-chrome-*.zip` asset from the [latest release](https://github.com/arthurjarvis02/itvx-adblocker/releases/latest), extract it, then go to `chrome://extensions`, enable Developer mode, and "Load unpacked" pointing at the extracted folder.

### Firefox
Click .xpi file from [latest release](https://github.com/arthurjarvis02/itvx-adblocker/releases/latest)
